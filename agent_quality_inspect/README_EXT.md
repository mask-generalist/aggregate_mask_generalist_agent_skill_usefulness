# Agent Quality Inspect — Extension

This is our extension of the open-source [Agent Quality Inspect](README.md)
library. We build on its "Talk, Evaluate, Diagnose" methodology and add new
metrics not present in the upstream package:

- **Capability Correctness**
- **Skill Precision**
- **Skill Recall**

## Running the extended library

The extended library runs the same way as the original. For setup and usage
instructions, refer to the original Agent Quality Inspect documentation in
[`README.md`](README.md).
